# Corações Número

Mod cliente para Minecraft 1.20.1 / Forge 47.2.0. Requer Java 17.

## Compilar localmente

Clone o repositório e execute na pasta do projeto:

```bash
gradle build
```

O JAR será gerado em `build/libs/`.

## Compilar pelo GitHub

O workflow em `.github/workflows/build.yml` compila automaticamente em cada push/ pull request e permite iniciar uma compilação manual pela aba **Actions**. O JAR compilado fica disponível como artefato `coracoes-numero-1.0.0`.
